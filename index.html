모두의 할인 개인정보처리방침

운영자: LavaTree · 공고 및 시행일: 2026년 11월 20일 · 문서 버전: 2026-11-20

할인 목록과 내 주변 지도는 회원가입 없이 이용할 수 있습니다. 회원 기능은 만 14세 이상에게 제공하며, 간편로그인과 계정별 브랜드 찜 동기화를 이용할 때 아래 정보를 처리합니다. 회원 기능이 없는 이전 앱 버전은 해당 기능의 정보를 수집하지 않습니다.

LavaTree(이하 ‘운영자’)는 모두의 할인 서비스의 개인정보 처리 항목, 이용 목적, 보관 기간과 이용자의 권리를 다음과 같이 안내합니다.

1. 수집 항목과 이용 목적

간편로그인 및 회원 관리
카카오·네이버·Apple이 발급한 서비스별 이용자 식별자, 선택한 로그인 제공자, 모두의 할인 회원 ID, 계정 생성·로그인 시각, 인증 세션 정보를 처리합니다. Apple에서 전달한 이메일(‘나의 이메일 가리기’ 주소 포함)과 이름이 있는 경우 함께 저장될 수 있습니다. 카카오와 네이버는 현재 이메일·전화번호·프로필·생년월일을 요청하지 않습니다. 목적은 회원 식별, 로그인 유지, 본인 확인과 탈퇴 처리입니다. 간편로그인 서비스의 비밀번호는 운영자가 받지 않습니다.
브랜드 찜
회원 ID에 연결된 브랜드, 찜 여부와 변경 시각을 저장하여 같은 계정으로 로그인한 기기 사이에서 찜을 동기화합니다. 해제한 찜이 예전 기기의 데이터로 다시 추가되지 않도록 해제 상태도 회원 기간 동안 보관합니다.
회원 이용 동의
만 14세 이상이라는 확인 결과, 개인정보 수집·이용에 동의한 문서 버전과 시각을 저장합니다. 실제 생년월일이나 신분증을 수집하지 않습니다. 목적은 회원 기능 제공 조건과 동의 내역의 확인입니다.
장애 대응 및 서비스 보안
인증·서버 요청 과정에서 IP 주소, 요청 시각·주소, 응답 상태, 브라우저·기기 정보 등 기술 로그가 서비스 제공자의 시스템에 생성될 수 있습니다. 서비스 안정성과 보안, 오류 확인에 사용합니다. 운영자는 비밀번호·인증 코드·개인키를 문의로 요구하지 않으며 인증 토큰을 애플리케이션 로그에 기록하지 않습니다.
문의 처리
이용자가 이메일 문의 시 제공한 회신 주소, 문의 내용과 처리 내역을 문제 해결과 권리 요청 처리에 사용합니다. 필요한 최소 정보만 보내 주세요.

회원 기능의 필수 수집·이용 동의를 거부하거나 철회할 수 있습니다. 거부하면 회원 기능을 사용할 수 없지만 기본 할인 조회와 지도는 계속 이용할 수 있습니다. 현재 회원정보를 판매하거나 광고 타기팅에 이용하지 않으며 별도의 광고·행동분석 SDK를 운영하지 않습니다.

2. 내 주변 지도와 외부 서비스

현재 위치를 선택하면 운영체제 또는 브라우저의 위치 권한을 요청합니다. 허용한 위치 좌표, 지도 중심점, 검색어는 주변 매장 검색을 위해 카카오 지도 서비스에 전달될 수 있습니다. 이 정보를 모두의 할인 회원 DB에 저장하거나 회원 찜과 연결하여 위치 이력을 만들지 않습니다. 위치 권한을 거부해도 지역 검색과 지도 이동으로 사용할 수 있습니다. 기기 설정에서 언제든 위치 권한을 철회할 수 있습니다.

지도·외부 혜택 앱·브랜드 사이트 이용 시 해당 서비스가 IP 등 접속 정보를 직접 처리할 수 있으며 해당 사업자의 방침이 적용됩니다. 외부 링크에 모두의 할인 회원 ID나 찜 목록을 추가하여 보내지 않습니다.

3. 기기에 저장되는 정보

  • 로그인 유지에 필요한 인증 세션, 계정별 찜 캐시, 기존 할인 알림 설정을 앱 또는 브라우저 저장소에 저장합니다.
  • ‘최근 로그인’ 안내에는 마지막으로 로그인에 성공한 제공자의 종류만 저장합니다. 동일인 판정이나 서로 다른 계정의 자동 연결에 사용하지 않습니다. 로그아웃해도 이 안내는 남을 수 있습니다.
  • 회원 기능 도입 전 비회원 찜은 별도로 보관하며, 이용자가 ‘가져오기’를 선택한 경우 현재 계정에 추가합니다. 다른 계정의 찜과 자동으로 합치지 않습니다.
  • 앱 데이터 또는 브라우저 사이트 데이터 삭제로 기기 저장 정보를 지울 수 있습니다. 기기 데이터 삭제만으로 서버 계정이 탈퇴되지는 않습니다. 웹에서는 기존 앱의 로컬 알림 기능을 제공하지 않습니다.

4. 보유 기간과 파기

  • 회원 계정, 계정에 연결된 찜·해제 상태와 동의 기록: 회원 탈퇴 완료 시 운영 DB에서 삭제합니다. 인증 세션도 함께 제거합니다.
  • 기기 저장 정보: 해당 기기에서 탈퇴하면 그 계정의 찜 캐시·알림 설정·최근 로그인 안내를 정리합니다. 비회원 원본과 다른 계정의 데이터는 별도로 남습니다. 오프라인 상태인 다른 기기에 남은 캐시는 원격에서 즉시 지울 수 없으며 해당 기기의 앱·사이트 데이터 삭제로 제거할 수 있습니다.
  • 현재 사용 중인 Supabase Free 요금제의 인증 감사 및 API·DB 로그 조회 보관 기간은 1일입니다. 로그는 계정 데이터와 별도로 자동 만료됩니다. 운영자가 별도의 회원 DB 백업을 만들거나 장기 분석용으로 복제하지 않습니다. 요금제와 보관 정책 변경 시 방침을 갱신합니다.
  • 개인정보 관련 문의: 처리 완료 후 30일 이내에 문의 메일과 사본을 삭제합니다. 법령에 따라 별도 보관이 필요한 경우 해당 근거와 기간을 안내하고 다른 목적으로 사용하지 않습니다.

전자 데이터는 운영 시스템에서 삭제하여 더 이상 서비스에 이용하지 않습니다. 클라우드 제공자가 자체 보안·법적 의무에 따라 처리하는 기술 자료에는 해당 제공자의 보관 정책이 적용됩니다.

5. 회원 탈퇴와 계정 삭제 요청

  1. 가입할 때 사용한 방법으로 모두의 할인에 로그인합니다.
  2. MY → 회원 탈퇴에서 삭제 범위를 확인합니다. 본인 확인을 위해 로그인 후 10분 안에 진행해야 하며, 시간이 지났으면 다시 로그인해 주세요.
  3. 확인란에 ‘탈퇴’를 입력하고 계정과 찜 삭제하고 탈퇴를 누릅니다.

이 과정은 모두의 할인 연결을 해제하고 회원 계정·찜·동의 기록을 삭제합니다. 카카오·네이버·Apple 계정 자체는 삭제하지 않습니다. 완료 전 오류가 발생하면 삭제 완료로 간주하지 않으며 다시 시도하거나 문의해 주세요. 삭제한 찜은 재가입해도 복구되지 않습니다. 다른 로그인 제공자로 별도 가입한 계정이 있으면 각 계정에서 탈퇴해야 합니다.

앱을 이용할 수 없거나 로그인할 수 없는 경우에도 계정 삭제 요청 이메일을 보낼 수 있습니다. 사용한 로그인 방법과 회신 받을 주소를 알려 주세요. 계정 소유를 확인하는 최소 절차를 안내하고 삭제 결과를 회신합니다. 비밀번호·인증 코드·신분증을 먼저 보내지 마세요. 단순 로그아웃이나 제공자 앱에서의 연결 해제는 모두의 할인 탈퇴 완료와 다를 수 있으므로 위 절차를 이용해 주세요.

6. 처리 위탁 및 국외 처리 안내

운영자는 서비스 제공에 필요한 아래 처리 업무를 외부 서비스에 맡깁니다. 회원 데이터의 주 저장 DB는 대한민국 서울 리전이며, 해외 사업자의 인증·클라우드 운영과 지원 과정에는 국외 처리가 수반될 수 있습니다.

7. 이용자의 권리와 보호 조치

이용자는 개인정보 열람·정정·삭제·처리정지·동의 철회를 요청할 수 있습니다. 앱의 탈퇴 기능 또는 아래 문의처를 이용해 주세요. 요청자 본인 확인에 필요한 최소 정보를 확인하고 관련 법령에 따라 처리합니다. 운영자는 회원 데이터 접근 권한 제한, 인증된 본인 데이터만 처리하는 서버 검증, 암호화된 서비스 통신, 운영 비밀값의 분리 보관을 적용합니다.

8. 만 14세 미만 이용자

회원 기능은 만 14세 이상에게만 제공합니다. 법정대리인 동의를 통한 아동 회원가입은 제공하지 않습니다. 만 14세 미만은 로그인 없이 기본 할인 정보와 지도를 이용할 수 있습니다. 만 14세 미만의 회원 정보가 잘못 수집된 사실을 알게 되면 확인 후 삭제합니다. 관련 사실은 아래 문의처로 알려 주세요.
