모두의 할인 개인정보처리방침

시행일: 2026년 11월 17일

모두의 할인(이하 “앱”)은 이용자의 개인정보를 중요하게 생각하며, 이용자가 앱을 안심하고 이용할 수 있도록 개인정보 처리와 관련된 사항을 다음과 같이 안내합니다.

현재 모두의 할인은 회원가입 또는 로그인을 제공하지 않으며, 이용자를 직접 식별하기 위한 개인정보를 자체 서버에 수집하거나 저장하지 않습니다. 내 주변 기능에서는 선택적 위치 권한과 카카오맵을 사용합니다. 위치 및 외부 서비스 통신에 관한 내용은 아래에 안내합니다.

1. 개인정보의 수집

현재 모두의 할인은 회원가입 또는 로그인을 제공하지 않습니다. 또한 이름, 이메일 주소, 전화번호, 주소, 위치정보, 결제정보 등 이용자를 직접 식별하기 위한 개인정보를 앱 자체 서버에 수집하거나 저장하지 않습니다.

앱에서 사용하는 찜 목록 및 알림 설정 등의 정보는 이용자의 기기에 로컬로 저장되며, 모두의 할인 서버 계정과 연동하여 저장하지 않습니다.

자체 서버에 위치정보를 저장하지 않는다는 것은 기기에서 위치를 사용하지 않거나 외부 지도 서비스와 통신하지 않는다는 뜻은 아닙니다. 내 주변 기능의 위치 이용과 카카오로 전달되는 정보는 다음 항목을 따릅니다. 해당 기능의 제공 여부는 앱 버전에 따라 다를 수 있습니다.

2. 서비스 제공을 위한 네트워크 통신

모두의 할인은 최신 할인 정보를 제공하기 위해 인터넷을 통한 네트워크 통신을 수행합니다.

공개된 할인 데이터를 제공하기 위한 데이터베이스 및 백엔드 서비스로 Supabase를 사용합니다.

이 과정에서 모두의 할인은 이용자의 찜 목록, 알림 설정 또는 개인 식별 정보를 Supabase에 저장하지 않습니다.

다만 인터넷 서비스의 일반적인 동작 과정에서 네트워크 또는 인프라 서비스 제공자가 보안, 장애 대응 및 서비스 운영을 위해 IP 주소, 접속 시각 등의 기술적 정보를 처리할 수 있으며, 이러한 정보의 처리는 해당 서비스 제공자의 정책에 따를 수 있습니다.

내 주변 지도와 위치 권한

내 주변 기능은 이용자가 위치 접근을 허용한 경우 현재 위치를 확인하여 지도에 표시하고 주변 매장을 찾는 데 사용합니다. 이미 위치 권한이 허용된 경우 내 주변 화면에 처음 들어갈 때 현재 위치를 확인할 수 있습니다. 위치 권한은 선택 사항이며, 허용하지 않아도 지역 검색과 지도 이동으로 이용할 수 있습니다. 앱은 백그라운드 위치 추적을 수행하지 않습니다.

지도 표시와 장소 검색에는 카카오맵 JavaScript API를 사용합니다. 지도 표시 과정에서 표시 범위에 해당하는 지도 데이터 요청이 발생하며, 지역·매장 검색 시 검색어 또는 브랜드명, 선택한 검색 중심 좌표와 검색 반경 등이 카카오에 전달됩니다. 현재 위치를 중심으로 매장을 검색하면 해당 좌표에 이용자의 현재 위치가 포함됩니다. 이 요청은 기기에서 카카오로 전송되며 모두의 할인 자체 서버나 Supabase를 경유하여 저장하지 않습니다.

지도 페이지는 GitHub Pages에서 제공됩니다. 지도 페이지와 카카오 서비스에 접속할 때 IP 주소, 접속 시각, 브라우저 등 통신에 필요한 기술 정보가 서비스 제공자에게 전달될 수 있습니다. 각 제공자의 보관·처리 범위는 해당 정책을 따르며, 모두의 할인에서 저장하지 않는다는 설명이 외부 제공자의 로그 미보관을 의미하지는 않습니다. 카카오 개인정보처리방침과 GitHub 개인정보처리방침을 참고해 주세요.

선택 권한의 변경

위치 권한은 기기의 설정에서 모두의 할인 앱의 위치 권한을 변경하거나 철회할 수 있습니다. 웹에서는 브라우저의 사이트 위치 권한 설정을 이용합니다. 위치 권한을 거부하거나 철회해도 할인 목록과 상세 정보, 지역 검색은 사용할 수 있습니다. 할인 알림 권한도 선택 사항이며 기기의 알림 설정에서 변경할 수 있습니다.

3. 개인정보의 이용 목적

모두의 할인은 현재 이용자를 식별할 수 있는 개인정보를 별도로 수집하여 광고, 개인 맞춤형 마케팅 또는 사용자 프로파일링에 이용하지 않습니다.

앱에서 이루어지는 네트워크 통신은 공개 할인 정보의 조회 및 앱 기능 제공을 위한 목적으로 사용됩니다.

4. 개인정보의 제3자 제공 및 판매

모두의 할인은 이용자의 개인정보를 판매하지 않습니다.

또한 광고 또는 마케팅을 목적으로 이용자의 개인정보를 제3자에게 제공하지 않습니다.

서비스 제공을 위해 Supabase(공개 할인 정보), GitHub Pages(지도 페이지), 카카오(지도 표시·장소 검색) 등 기술 서비스 제공자가 위에 설명한 네트워크 통신을 처리할 수 있습니다. 각 서비스 제공자의 처리에 관한 내용은 해당 정책을 따릅니다.

5. 광고 및 분석 도구

현재 모두의 할인은 광고 SDK를 사용하지 않습니다.

또한 현재 별도의 사용자 행동 분석용 Analytics SDK 또는 Crash Reporting SDK를 사용하지 않습니다.

향후 이러한 기능이 추가되어 데이터 처리 방식이 변경되는 경우 본 개인정보처리방침 및 관련 안내를 함께 갱신합니다.

6. 기기에 저장되는 데이터

앱 기능 제공을 위해 다음과 같은 정보가 이용자의 기기에 로컬로 저장될 수 있습니다.

  • 찜한 브랜드 및 할인 관련 정보
  • 할인 알림 설정
  • 앱 기능 제공을 위해 필요한 로컬 설정 정보

이러한 정보는 현재 모두의 할인 서버의 사용자 계정과 동기화되지 않습니다.

7. 데이터의 보관 및 삭제

현재 모두의 할인은 회원 계정이나 이용자를 직접 식별하기 위한 개인정보를 자체 서버에 저장하지 않습니다.

이용자의 기기에 저장된 찜 목록, 알림 설정 및 기타 로컬 데이터는 앱을 삭제하거나 운영체제의 앱 데이터 삭제 기능을 사용하여 삭제할 수 있습니다.

현재 위치와 주변 매장 검색 결과는 현재 화면의 동작에 필요한 메모리 상태로만 유지하며, 앱의 로컬 영구 저장소나 모두의 할인 자체 서버에 저장하지 않습니다. 새 검색으로 표시 결과가 교체되며, 앱 실행이 종료되면 메모리 상태가 정리됩니다. 외부 서비스의 접속 기록 등은 각 제공자의 정책에 따릅니다.

향후 회원 기능 또는 서버 동기화 기능이 추가되는 경우 데이터의 보관 기간, 삭제 방법 및 관련 절차를 별도로 안내하고 본 개인정보처리방침을 갱신합니다.
